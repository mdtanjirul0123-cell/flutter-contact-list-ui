# Flutter Contact List UI

A Flutter application showcasing a contact list user interface.

## Getting Started

This project is a starting point for a Flutter application.

### Prerequisites

- Flutter SDK installed ([Install Flutter](https://flutter.dev/docs/get-started/install))
- A code editor (VS Code, Android Studio, or IntelliJ)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/mdtanjirul0123-cell/flutter-contact-list-ui.git
cd flutter-contact-list-ui
```

2. Get Flutter packages:
```bash
flutter pub get
```

3. Run the app:
```bash
flutter run
```

## Project Structure

```
lib/
├── main.dart              # Entry point of the application
```

## Features

- Contact list display
- Add new contacts
- Material Design UI
